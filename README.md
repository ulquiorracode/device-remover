# Device Remover (dr)

**Device Remover (`dr`)** — это высокопроизводительная, легковесная консольная утилита и TUI-панель на C# (.NET 10), предназначенная для быстрого включения и отключения встроенного оборудования ноутбуков (тачпад, встроенная клавиатура, веб-камера и др.) через Win32 SetupAPI. 

Проект разработан с прицелом на максимальную производительность: полностью оптимизирован под **Native AOT** (компиляция в один бинарный файл без зависимостей), использует эффективное ручное управление памятью (`stackalloc`, `ArrayPool` и структуры без аллокаций в куче) и не вызывает предупреждений тримминга.

---

## Возможности / Features

- 💻 **Интерактивный TUI-интерфейс**: красивое интерактивное меню на стрелочках для переключения профилей или отдельных устройств.
- ⚡ **Мгновенный запуск**: старт программы за считанные миллисекунды за счет Native AOT и отсутствия тяжелых CLI-фреймворков на рефлексии.
- ⚙️ **Простая конфигурация**: конфиг в формате JSON хранится в `%APPDATA%\device-remover\config.json` и поддерживает короткие псевдонимы (алиасы).
- 🔍 **Гибкий поиск устройств**: поиск по `Instance ID`, `Hardware ID` или `Friendly Name` с поддержкой регулярных выражений (Regex) и масок (Wildcards).
- 🛡️ **Автоматический запрос прав UAC**: если утилита запущена без прав администратора, она сама запросит повышение прав только при изменении состояния железа.

## Установка и запуск / Installation

### Компиляция в Native AOT
Для сборки одного независимого `.exe` файла размером около 2-3 МБ:

1. Установите [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).
2. Склонируйте репозиторий и выполните команду сборки:
   ```bash
   dotnet publish -c Release -r win-x64
   ```
3. Собранный файл будет находиться в директории `bin\Release\net10.0\win-x64\publish\device-remover.exe`. Его можно переименовать в `dr.exe` и добавить в системную переменную `PATH`.

## Использование / Commands

Запуск без аргументов открывает интерактивный TUI:
```bash
dr
```

### Команды управления устройствами:
- `dr status` — вывести красивую таблицу со статусом всех настроенных алиасов и устройств в системе.
- `dr search <запрос>` — найти устройство в системе и подсветить совпадения. Полезно для поиска ID новой клавиатуры или тачпада.
- `dr disable [alias1,alias2,...]` (синоним: `dr remove`) — отключить устройства по алиасам. Если запустить без аргументов, утилита будет запрашивать алиасы по очереди.
- `dr enable [alias1,alias2,...]` (синоним: `dr restore`) — включить устройства по алиасам.

### Команды настройки алиасов (`dr alias`):
- `dr alias list` — список всех алиасов.
- `dr alias add <имя> <паттерн> [опции]` — создать или обновить алиас.
  - `-f, --field <поле>` — где искать: `Any`, `InstanceId`, `HardwareId`, `FriendlyName` (по умолчанию `Any`).
  - `-m, --mode <режим>` — режим поиска: `Contains`, `Exact`, `Regex`, `Wildcard` (по умолчанию `Contains`).
  - `-d, --desc <описание>` — понятное описание устройства.
- `dr alias remove <имя>` — удалить алиас.
- `dr alias rename <старое>=<новое>` — переименовать алиас.

### Команды профилей (`dr profile`):
- `dr profile list` — список доступных профилей.
- `dr profile active` — показать текущий активный профиль.
- `dr profile apply <имя>` — применить профиль (переключить состояния всех связанных устройств).
- `dr profile add <имя> [--desc <описание>]` — добавить пустой профиль.
- `dr profile set <имя> <алиас>=<Enabled|Disabled>` — связать состояние алиаса с профилем.
- `dr profile remove <имя>` — удалить профиль.

## Конфигурация / Configuration

Конфигурационный файл автоматически создается при первом запуске по пути:
`%APPDATA%\device-remover\config.json`

### Пример файла конфигурации:
```json
{
  "Aliases": {
    "keyboard": {
      "Description": "Встроенная клавиатура ноутбука (обычно PS/2)",
      "MatchField": "InstanceId",
      "MatchMode": "Contains",
      "Value": "ACPI\\PNP0303"
    },
    "touchpad": "VID_04F3&PID_304B"
  },
  "Profiles": {
    "docked": {
      "Description": "Внешняя периферия подключена. Встроенные клавиатура и тачпад отключены.",
      "Devices": {
        "keyboard": "Disabled",
        "touchpad": "Disabled"
      }
    },
    "mobile": {
      "Description": "Режим в дороге. Встроенное управление включено.",
      "Devices": {
        "keyboard": "Enabled",
        "touchpad": "Enabled"
      }
    }
  },
  "ActiveProfile": "mobile"
}
```

> **Примечание:** Алиасы можно описывать как простыми строками (например, `"touchpad": "VID_04F3&PID_304B"`), так и объектами со специфическими параметрами поиска.
